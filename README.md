# Meteo — Grafite

Interfaccia meteo scura, realizzata con Vite e React dal mockup "1b — Grafite".

```bash
npm install
npm run dev
```

I dati meteo arrivano da [Open-Meteo](https://open-meteo.com/), gratuito per uso non commerciale e senza chiave API. Le chiamate sono in `src/api/weather.js`; le città nel menu in `src/data/cities.js`.
